# Chronos ⏱️

A planned productivity and time-management project focused on helping people organise tasks and make their time easier to manage.

> **Status: Concept / not yet implemented.** This repository currently documents the direction of the project; it does not claim to contain a working application.

## 🎯 Goal

Build a small, understandable productivity tool and grow it step by step as programming skills develop.

## 🧭 Possible Features

- Create, edit, and complete tasks
- Set priorities and due dates
- View tasks by day or status
- Track completed work
- Save data between sessions
- Add a simple interface after the core logic works

These are ideas for future development, not existing features.

## 🗺️ Development Roadmap

- [ ] Define the first version and keep the scope small
- [ ] Build a command-line prototype
- [ ] Add input validation and clear error messages
- [ ] Add persistent storage
- [ ] Write tests for core behaviour
- [ ] Document screenshots and usage once a working interface exists

## 🧰 Planned Learning Areas

Python fundamentals, functions, data structures, file handling, testing, and Git/GitHub workflow.

## 🔐 Development Notes

Use sample data only. Never commit passwords, API keys, private information, or personal task data.
